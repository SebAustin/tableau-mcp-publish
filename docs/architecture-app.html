MCP Server · Architecture

From one prompt to a governed, branded, beautiful Tableau workbook

A stateless MCP server pairs a deterministic TypeScript planner with a Python sidecar that hand-builds XSD-validated Tableau XML. Design knowledge is mined, not guessed — from the top-100 Viz-of-the-Day workbooks — and every generated dashboard can critique itself against those norms.

Tool surface — 8 families

Design knowledge is mined, then applied

The corpus is a committed, deterministic knowledge layer — never embeddings. Norms carry an n and a confidence; a low-n bucket (n < 15) never drives an automatic decision. Themes cite mined recipes by sha256; a test fails the build if a theme invents a value.

Nothing is published without a confirmed plan

design_dashboard returns a proposal wrapping the exact machine plan; the caller can edit it — story captions, KPI comparisons — and critique_dashboard scores it against the mined norms before build_from_plan, the one side-effecting tool, publishes.
